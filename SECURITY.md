# Security policy

Report vulnerabilities in the packaged UQDA software through the private
process documented at https://github.com/Uqda/Core/security/policy. Packaging
problems may be reported privately through this repository's Security tab.

Never attach private keys or `/etc/uqda.conf` to a public report. Official
releases publish SHA-256 manifests, Sigstore bundles, and GitHub provenance
attestations. RPM-level GPG repository signing is separate and will be required
before enabling a future DNF/COPR repository.
